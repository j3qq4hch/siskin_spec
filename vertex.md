# `<vertex>`

*вершина полигона — точка обхода, с прогибом*

| | |
|---|---|
| **Встречается в** | полигон |
| **Родители** | [`<polygon>`](polygon.md) |
| **Дети** | — |

## Атрибуты

| Атрибут | Тип / единицы | Смысл |
|---|---|---|
| `x` `y` | Целое, [µm](units.md) | Точка контура |
| `curve` | Целое знаковое, [мград](units.md), опционально | Прогиб ребра **к следующей вершине**; отсутствие = ребро прямое |

## Ребро принадлежит вершине-началу

Контур полигона — цепочка рёбер: от каждой вершины к следующей, от последней —
**замыкание к первой**. `curve` описывает ребро, выходящее из этой вершины,
поэтому дуговое замыкание записывается на последней вершине.

Семантика `curve` — та же, что у [`<arc>`](arc.md): угол дуги, знак — сторона
выпуклости (`+` — центр слева от хорды по ходу обхода). Те же пределы: не
`±360000`; `0` не пишется — прямое ребро кодируется отсутствием атрибута.

Это концевая форма и здесь: обе вершины дугового ребра лежат на целой
µm-решётке, стыки рёбер точны по построению.

## Правила

- Обход — **против часовой стрелки** (CCW), см. [`<polygon>`](polygon.md).
- Подряд совпадающие вершины запрещены — ребро нулевой длины не несёт ничего.
- Флага замыкания нет: контур замкнут по построению.
