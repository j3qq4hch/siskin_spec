# `<library>`

*корень файла `.swlib` — три пула и ничего больше*

| | |
|---|---|
| **Встречается в** | библиотека |
| **Родители** | — (корень) |
| **Дети** | [`<symbol>`](symbol.md), [`<footprint>`](footprint.md), [`<component>`](component.md) |

## Атрибуты

| Атрибут | Тип / единицы | Смысл |
|---|---|---|
| `name` | Строка | Имя библиотеки |

## Описание

Библиотека — это **три независимых пула**:

```xml
<library name="rt">
  <symbol name="R">        … </symbol>      <!-- графика символов -->
  <footprint name="R0603"> … </footprint>   <!-- графика корпусов -->
  <component name="RESISTOR" prefix="R">    <!-- семейства -->
    <gate   name=""       symbol="R"    x="0" y="0" />
    <device name="-0603"  footprint="R0603"> … </device>
  </component>
</library>
```

Первые два — чистая геометрия, друг о друге они не знают. Третий связывает их:
[`<gate>`](gate.md) берёт символ, [`<device>`](device.md) — корпус.

**Имена символов и корпусов уникальны в пределах библиотеки** — по ним и идут
ссылки. Имена [устройств](device.md) уникальны лишь внутри своего компонента.

## Тот же состав внутри проекта

[`<project>`](project.md) содержит те же три пула — библиотечное содержимое
**вкомпилировано** в него, а не подключено ссылкой. Проект самодостаточен: чтобы
его открыть, внешние файлы не нужны.

Обратное движение тоже возможно: **из проекта можно выгрузить библиотеку** с теми
устройствами, которые в нём использованы.

## Правила

- `name` уникально среди библиотек проекта — им квалифицируются ссылки.
- Пул может быть пуст: библиотека только с символами законна.
- Символ или корпус, на который никто не ссылается, — не ошибка. Это заготовка.
