# `<line>`

*отрезок — базовый штрих всей геометрии*

| | |
|---|---|
| **Встречается в** | символ, корпус, модуль, схема, сегмент цепи, плата, сигнал |
| **Родители** | [`<symbol>`](symbol.md), [`<footprint>`](footprint.md), [`<module>`](module.md), [`<schematic>`](schematic.md), [`<segment>`](segment.md), [`<layout>`](layout.md), [`<signal>`](signal.md) |
| **Дети** | — |

## Атрибуты

| Атрибут | Тип / единицы | Смысл |
|---|---|---|
| `x1` `y1` | Целое, [µm](units.md) | Начало |
| `x2` `y2` | Целое, [µm](units.md) | Конец |
| `width` | Целое, [µm](units.md) | Толщина штриха |
| `layer` | [Номер слоя](layer-model.md) | Где лежит. **Не пишется** внутри [сегмента цепи](segment.md) |

## Один тег — три роли

Что означает отрезок, решает **контейнер**, не атрибут:

| Родитель | Роль |
|---|---|
| [`<segment>`](segment.md) | **провод схемы** — электрическая связь; `layer` не пишется, принадлежность цепи даёт сам контейнер |
| [`<signal>`](signal.md) | **дорожка** — медь цепи, `layer` [медный](layer-model.md); на `146` — [металлизированный торец](signal.md) той же цепи |
| всё остальное | графика: контур символа, шёлкография, [контур платы](layout.md), документация |

Это прямое следствие правила «[слой ничего не решает структурно](layer-model.md)»:
`<line layer="91">` на холсте — декорация, а не цепь; проводом отрезок делает
только жизнь внутри [`<net>`](net.md).

## Штрих пера

Отрезок — след **круглого пера** толщиной `width`: концы полукруглые, радиусом
`width/2`. Поэтому цепочка отрезков с общими концами сплошна **по построению** —
стык накрыт полукружиями обоих штрихов, никакой обработки соединений не нужно.
Та же семантика пера у [дуги](arc.md) и у контура [полигона](polygon.md).

## `width="0"` — волосяная линия

Ноль означает «толщины нет»: линия рисуется минимально видимой, физического тела
не несёт. Законна в графике и на контуре платы — рез идёт по осевой, ширину
инструмента выбирает фабрика. **На меди запрещена**: у дорожки без толщины нет
физического смысла.

Паз или рез заданной ширины — та же линия на слое [`120`](layer-model.md), где
`width` и есть ширина инструмента: `<line layer="120" width="2000" …/>` — паз 2 мм.

На [`146`](signal.md) толщины нет **по построению**: геометрию стенки задаёт сам
рез, а след на `146` только называет его участок. Пишется `0`.

## Правила

- **На меди `width > 0`** — и не меньше `min_width` из [правил платы](rules.md).
- Внутри [`<segment>`](segment.md) атрибут `layer` не пишется: слой проводов —
  конвенциональный `91`, а принадлежность цепи задаёт контейнер.
- Вырожденный отрезок (`x1 y1` = `x2 y2`) — точка пера: диск диаметром `width`.
  Законен, но провод нулевой длины в сегменте бессмыслен.
