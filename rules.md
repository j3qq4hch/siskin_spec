# `<rules>`

*DRC-ядро платы — шесть чисел от фабрики*

| | |
|---|---|
| **Встречается в** | плата |
| **Родители** | [`<layout>`](layout.md) |
| **Дети** | — |

## Атрибуты

Все — целые [µm](units.md), все опциональны. Отсутствие атрибута = «не задано»,
**не ноль**.

| Атрибут | Смысл |
|---|---|
| `clearance` | Минимальный зазор медь ↔ медь разных цепей |
| `edge_clearance` | Минимальный зазор медь ↔ контур платы |
| `min_width` | Минимальная ширина меди — дорожек и штрихов заливки |
| `min_drill` | Минимальное сверло |
| `min_annular` | Минимальное кольцо [перехода](via.md) |
| `min_drill_web` | Минимальная перемычка между двумя отверстиями |

## Шесть чисел, не rule-engine

Это **возможности фабрики**, задаваемые один раз на плату — пол, ниже которого
физически нельзя. Не система правил: движки вроде Altium с
scope-выражениями и приоритетами сознательно не переносятся — маленький плоский
DRC проще перенастроить руками, чем транслировать чужой язык запросов. Импорт
берёт **общий дефолт платы**; правила с областью действия отбрасываются с
записью в лог, не угадываются.

Точечные ужесточения выражаются на своих местах, поверх пола:

| Надстройка | Где |
|---|---|
| ширина/сверло/зазор группы цепей | [класс цепи](class.md) |
| локальный зазор одной заливки | [`clearance` полигона](polygon.md) |

Эффективное значение всегда `max(локальное, пол платы)` — надстройка только
**добавляет**, опуститься ниже пола нельзя.

## Одна пара зазоров, не шесть

Инструменты любят раздавать зазор попарно: провод↔провод, провод↔пад, пад↔виа…
Физика у фабрики одна — травление меди, — поэтому в IR один `clearance`.
Импорт расходящихся пар берёт **максимум** (безопасное для производства слияние)
и пишет об этом в лог.

## Правила

- Не больше одного `<rules>` на плату; по конвенции — первый ребёнок
  [`<layout>`](layout.md).
- Отсутствие тега законно: проект без знаний о фабрике — нормальное состояние
  (сказать «зазор 0» он не пытается).
- У каждой платы проекта — свои правила: фабрика — факт платы, не проекта.
- Числа — **пол, не цель**: редактор не даёт инструментам опуститься ниже,
  DRC проверяет уже нарисованное.
