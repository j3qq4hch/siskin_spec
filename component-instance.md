# `<compinst>`

*экземпляр компонента — вхождение детали на лист схемы*

> 🟡 **Изменение формата, решено 2026-07-31, в коде не сделано.**
> Раньше тег назывался `<instance>` и обслуживал два понятия сразу; экземпляр
> модуля отличался наличием атрибута `module`. См. [reasoning.md](reasoning.md).

| | |
|---|---|
| **Встречается в** | схема, модуль |
| **Родители** | [`<schematic>`](schematic.md), [`<module>`](module.md) |
| **Дети** | [`<attr>`](attr.md), [`<text>`](text.md) |

## Атрибуты

| Атрибут | Тип / единицы | Смысл |
|---|---|---|
| `name` | Строка | Designator — `R1`, `IC3`. Уникален в пределах схемы |
| `component` | Строка | Имя [компонента](component.md) |
| `library` | Строка | Библиотека, в которой он лежит. Одноимённые компоненты из разных библиотек различаются только этим |
| `gate` | Строка | Какая [секция](gate.md) размещена. Пустое имя — обычный случай |
| `device` | Строка | Какое [устройство](device.md) семейства взято |
| `x` `y` | Целое, [µm](units.md) | Точка вставки символа |
| `rot` | Целое, [мград](units.md) | Поворот. [Кратен `90000`](units.md) |
| `mirror` | `0` / `1` | Зеркальное отражение |

## Секция размещается отдельно

Экземпляр — это **одна секция**, а не весь компонент. Четырёхсекционный разъём
даёт четыре `<compinst>` с одним `name`, но разными `gate`:

```xml
<compinst name="CON1" library="Connectors" component="1734037-4" gate="A" … />
<compinst name="CON1" library="Connectors" component="1734037-4" gate="B" … />
```

Они могут стоять на разных страницах, но на плате это **один**
[`<element>`](element.md) — физическая деталь одна.

## Что переопределяет экземпляр

| Чем | Что задаёт |
|---|---|
| [`<attr>`](attr.md) | значения атрибутов — партномер, номинал |
| [`<text>`](text.md) | раскладку плейсхолдеров, см. [naming.md](naming.md) |

Список `<text>`, если он есть, **исчерпывающий**: что не перечислено — удалено,
а не унаследовано.

## Чем отличается от экземпляра модуля

Понятия разные настолько, что общего тега им мало:

| | `<compinst>` | [`<modinst>`](module-instance.md) |
|---|---|---|
| что внутри | деталь | кусок схемы |
| адрес | `library` + `component` + `device` + `gate` | `module` |
| [атрибуты](attr.md) | **есть** — партномер, номинал | нет |
| `offset` нумерации | нет | **есть** |
| вариант сборки | нет | **есть** |
| попадает на плату | как [`<element>`](element.md) | разворачивается в детали внутри |
| автопереименование | по `prefix` компонента | по своим правилам канала |

## Правила

- **`name` уникален в пределах схемы** — это адрес, по нему ссылается
  [`<pinref>`](pinref.md) и [`<element>`](element.md) на плате.
- Секции одного компонента делят `name`, различаются `gate`.
- `device` обязателен, если у компонента есть устройства: без него неизвестно,
  какой корпус ставить на плату.
