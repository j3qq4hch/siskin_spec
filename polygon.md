# `<polygon>`

*заполненный многоугольник — модель пера*

| | |
|---|---|
| **Встречается в** | символ, корпус, сигнал |
| **Родители** | [`<symbol>`](symbol.md), [`<footprint>`](footprint.md), [`<signal>`](signal.md) |
| **Дети** | [`<vertex>`](vertex.md) |

## Атрибуты

| Атрибут | Тип / единицы | Смысл |
|---|---|---|
| `layer` | [Номер слоя](layer-model.md) | Где лежит |
| `width` | Целое, [µm](units.md) | Толщина пера контура — она же минимальная ширина меди и шаг штриховки |
| `fill` | Целое, `0`–`100`, умолчание `100` | Плотность заливки: `100` — сплошная, `0` — только контур, между — штриховка |
| `rank` | Целое, `1`–`6`, умолчание `1` | Приоритет при наложении заливок разных цепей — **меньший вытесняет**. Только на меди |
| `thermals` | `0` / `1`, умолчание `1` | Генерирует ли полигон термобарьеры на своих падах. Только на меди |
| `clearance` | Целое, [µm](units.md), опционально | Локальный зазор от чужой меди — поверх [`clearance` платы](rules.md). Только на меди |

## Модель пера

Полигон — **не зона**. Хранимый контур — это **осевая линия круглого
[пера](line.md) толщиной `width`**; медь полигона = след пера по контуру плюс
внутренность. Кромка меди торчит на `width/2` **наружу** от осевой — это не
погрешность, а честная геометрия хранимого.

Заливается внутренность **штрихами того же пера**: `fill` задаёт их скважность.
Отсюда три свойства по построению, которые в модели зоны требуют отдельного кода:

- **минимальная ширина меди невыразимо-нарушаема**: тоньше одного прохода пера
  меди просто не бывает, DRC-проверка не нужна;
- **термоспица — штрих пера**: её пол — `width`, отдельного параметра ширины
  спицы не существует;
- **никакой булевой обрезки заливки по контуру**: штрихи заходят под контурную
  обводку, медь поверх меди — медь.

## `fill` — физическая плотность, не стиль

Процент меди, который реально останется на плате и уйдёт в Gerber: тепловое
поведение, травление, вес. Одно число вместо пары «толщина штриха + зазор»
(они математически схлопываются в процент) и вместо отдельного стиля
отображения — как объект выглядит на экране, решают
[цвет и альфа слоя](layer.md).

`fill="0"` — предельный случай: контур пером есть, заливки нет вовсе.

## На меди и вне её

Смысл атрибутов определяет слой-контейнер, тег один:

| Слой | Что работает |
|---|---|
| медный, внутри [`<signal>`](signal.md) | всё: полигон — **медь цепи**, принадлежность даёт контейнер |
| любой другой (шёлк, маска, схема…) | только `width` и `fill` — декоративная заливка; `rank`, `thermals`, `clearance` физического смысла не имеют |

Имени цепи на полигоне **нет** — как у [дорожки](line.md), принадлежность
задаёт контейнер `<signal>`, не атрибут.

## `rank` — кто забирает спорную площадь

При наложении заливок разных цепей на одном слое **меньший `rank` сильнее**:
`1` заливается первым и забирает площадь, больший обтекает его с зазором.
Перекрытие равных рангов разных цепей — конфликт, который обязан поймать DRC.

Направление шкалы подтверждено всеми реализациями: Eagle — `rank` насквозь,
KiCad — `priority = 7 − rank`, Altium — `POURINDEX = rank`.

## Термобарьеры — два факта в двух местах

| Вопрос | Где живёт |
|---|---|
| Генерирует ли **полигон** барьеры вообще | здесь, `thermals` — да/нет |
| Насколько **пад** теплоизолирован | [`<smd>`](smd.md)/[`<pad>`](pad.md) `thermals` — шкала `0`–`100` |

Отдельного термозазора нет: зазор барьера ≡ разрешённый `clearance` полигона.
Ширина спицы производна от шкалы пада, её пол — `width` полигона.

## Вычитание — анти-слои

Полигон — **единственная заполняемая область**, и потому единственный объект,
из которого [анти-слои](layer-model.md) вычитают. Анти-объект на `!N` дырявит
полигоны слоя `N` по-полигонно, с сохранением идентичности: та же цепь, тот же
`fill`, тот же `rank` — просто с дырками.

## Правила

- **Контур замкнут по построению**: последняя [вершина](vertex.md) соединяется
  с первой, отдельного флага замыкания нет.
- Обход вершин — **против часовой стрелки** (CCW).
- `width > 0` всегда — перо без толщины не оставляет следа; на меди — не меньше
  `min_width` из [правил платы](rules.md).
- Эффективный зазор на меди = `max(clearance полигона, clearance платы)` —
  локальное значение только **добавляет** к полу фабрики, опуститься ниже нельзя.
- Минимум три вершины.
