# `<gate>`

*секция — вхождение символа в компонент*

> 🟡 **Изменение формата, решено 2026-07-31, в коде не сделано.**
> Гейт теперь у **каждого** компонента; атрибут `<component symbol="…">`
> упразднён. См. [CHANGES.md](CHANGES.md).

| | |
|---|---|
| **Встречается в** | компонент |
| **Родители** | [`<component>`](component.md) |
| **Дети** | — |

## Атрибуты

| Атрибут | Тип / единицы | Смысл |
|---|---|---|
| `name` | Строка, **может быть пустой** | Имя секции. Уникально в пределах компонента |
| `symbol` | Строка | Имя [символа](symbol.md) из пула библиотеки |
| `x` `y` | Целое, [µm](units.md) | Положение секции в раскладке компонента |

## Описание

Гейт — это **вхождение символа в компонент**. Секция четырёхканального разъёма,
один вентиль из шести в корпусе, одна половина сдвоенного ОУ.

**Гейт — единственный способ объявить символ**, даже для односекционного
компонента. Один механизм вместо двух: раньше односекционные объявляли символ атрибутом `<component symbol="R">`,
а многосекционные — детьми `<gate>`. Один и тот же факт записывался двумя
способами, и читатель формата обязан был знать оба.

```xml
<component name="RESISTOR" prefix="R">
  <gate name="" symbol="R" x="0" y="0" />        <!-- одна секция: имя пустое -->
  <device name="-0603" footprint="R0603">
    <map gate="" pin="1" pad="1" />
  </device>
</component>
```

Имя пустое по той же логике, что у [устройства](device.md): когда секция одна,
приписывать нечего.

## Зачем гейту имя

Потому что **один символ входит в компонент несколько раз, и его пины
размножаются**. Пример — четырёхсекционный разъём:

```xml
<gate name="A" symbol="CON-10P" x="0" y="0"       />
<gate name="B" symbol="CON-10P" x="0" y="-33020" />
<gate name="C" symbol="CON-10P" x="0" y="-66040" />
<gate name="D" symbol="CON-10P" x="0" y="-99060" />
```

Символ один, у него пины `1`…`10`. Значит пин `1` существует **четырежды**, и
адресовать его можно только парой «секция + пин» — именно поэтому
[`<map>`](map.md) несёт `gate` отдельным полем.

## На схеме секция ставится отдельно

Каждый гейт размещается своим [`<compinst>`](component-instance.md) с атрибутом `gate`.
Четырёхсекционный разъём — это четыре экземпляра на листе, возможно на разных
листах, но один физический [элемент](element.md) на плате.

## Правила

- **`name` уникально внутри компонента**; пустое имя — значение, а не отсутствие.
- **Гейтов может не быть вовсе** — но только если в корпусе нет
  [падов](pad.md). Тогда компонент живёт лишь на плате: логотип, крепёжная стойка,
  репер. Есть хоть один пад — символ обязателен, иначе к нему не подключиться.
  См. [`<component>`](component.md).
- `symbol` обязан существовать в пуле библиотеки.
