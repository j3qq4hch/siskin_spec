# `<junction>`

*точка соединения*

| | |
|---|---|
| **Встречается в** | сегмент |
| **Родители** | [`<segment>`](segment.md) |
| **Дети** | — |

## Атрибуты

| Атрибут | Тип / единицы | Смысл |
|---|---|---|
| `x` `y` | Целое, [µm](units.md) | Где стоит точка |

## Точка говорит «здесь соединено»

Два провода, пересекающиеся на листе, соединены **не всегда**: перекрёсток без
точки — это провода, идущие мимо друг друга. Точка снимает двусмысленность для
читателя.

```
   │              │
───┼───   мимо   ──●──   соединено
   │              │
```

Само соединение при этом **уже записано** тем, что оба провода лежат в одном
[`<segment>`](segment.md). Точка — не источник факта, а его **изображение**.

## Правила

- Точка живёт внутри того сегмента, чью связность рисует.
- Точка не на перекрёстке проводов бессмысленна — повод для линтера.
- **Связность из точек не выводится.** Убрал точку — схема стала хуже читаться,
  но соединение осталось: оно в структуре.
