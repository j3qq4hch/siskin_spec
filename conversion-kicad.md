# Из/в KiCad

*частности переноса; общие обязательства — в [контракте](conversion.md)*

## KiCad глазами IR

Расхождение моделей здесь самое глубокое из трёх, и держится оно на двух
свойствах KiCad.

**Связность выводится из координат.** Провод соединяет вывод потому, что его
конец лежит в той же точке, а не потому, что соединение объявлено. Отсюда
[исключение в контракте](conversion.md): импорт из KiCad неоднозначен по
устройству источника, и эта неоднозначность оплачивается один раз, на границе
входа.

**Устройства как понятия не существует.** У KiCad есть библиотека символов и
библиотека корпусов, а связывает их **свойство `Footprint` конкретного
экземпляра на схеме** — то самое поле, которым пользуется «Update PCB from
Schematic». Библиотеки [в понимании IR](device.md) в проекте KiCad нет.

Из второго свойства следует главное отличие этой страницы от
[Eagle](conversion-eagle.md): библиотека не читается, а **собирается**.

## Предусловия

Проверяются до начала работы. Не выполнены — конвертация не начинается; догадки
о том, как обойти неполный проект, [запрещены контрактом](conversion.md).

| Требование | Основание |
|---|---|
| Проект передан архивом **«Archive Project»** | в корне архива ровно один `.kicad_pro`, дающий однозначную точку входа |
| **3D-модели встроены в плату** средством KiCad «embed file» | пути вида `${KICAD6_3DMODEL_DIR}/…` на другой машине не разрешаются |
| `sym-lib-table` и `fp-lib-table` **разрешают каждый** использованный символ и корпус | см. ниже |
| Символы **полностью разрешены**, без `extends` | производный символ в архиве означает, что архив неполон: выполнить «Export Symbols to New Library…» и переархивировать |
| Плата сохранена **KiCad 10** или новее | более ранняя версия формата отвергается с требованием пересохранить |

**Почему библиотеки обязаны разрешаться.** Копия символа или корпуса, лежащая в
схеме или на плате, — это снимок, который мог разойтись с библиотекой. KiCad
позволяет отредактировать **одно** размещение через «Edit Symbol…» / «Edit
Footprint…», не трогая библиотеку, и на стороне корпуса не оставляет об этом
никакого видимого следа. Конвертер берёт геометрию **только из библиотеки**;
проект, где библиотека не найдена, отвергается, а не достраивается из снимка.

> Официальных библиотек KiCad конвертер не разыскивает и не восстанавливает.
> Их вкладывает в проект пользователь.

## Библиотека собирается из проекта

Раз library-level устройства в KiCad нет, оно **выводится из фактического
употребления**.

Пара символ↔корпус читается **со схемы**, с каждого размещённого экземпляра
отдельно. Так и обнаруживается настоящее семейство: `Device:C`, размещённый
двенадцать раз, у трёх экземпляров несёт `C_0805_2012Metric`, у остальных
`C_0603…`.

Символ, разрешающийся в **несколько разных корпусов** по своим экземплярам,
становится одним [`<component>`](component.md) с несколькими
[устройствами](device.md). Плата для этого не нужна: картина целиком видна из
схемы.

**`Value` устройством не становится никогда.** Это данные экземпляра, а не
семейства; на уровень [компонента](component.md) поднимаются только собственные
поля символа, разрешённые из библиотеки.

### Обратно: единица экспорта — компонент

| Что в IR | Что получает KiCad |
|---|---|
| компонент с **одним** устройством | символ, поле `Footprint` заполнено ссылкой в `.pretty` |
| компонент с **несколькими** устройствами | символ, поле `Footprint` **пустое** — корпус выбирается при проектировании |
| компонент **без** устройств | символ, поле `Footprint` пустое |
| символ, не входящий ни в одно устройство | **не экспортируется**: понятия «голый символ» в KiCad нет |
| каждый [`<footprint>`](footprint.md) | отдельный файл `.kicad_mod` в `{имя}.pretty/` |

Обе библиотеки — `{имя}.kicad_sym` и `{имя}.pretty/` — создаются всегда.

## Что теряется

### При импорте

| Что | Чем становится |
|---|---|
| **Формы падов**, которых нет в IR | прямоугольником; овальное сверло — круглым |
| **Пады без слоёв** (апертуры) | отбрасываются |
| **Шины** и шинные врезки | групповая запись не моделируется |
| **Изображения** на схеме | отбрасываются |
| **Директивы netclass** (flag, assignments, patterns) | отбрасываются: [класс — атрибут цепи](class.md), правил-шаблонов в IR нет |
| **`in_bom=no`** без `dnp` | игнорируется: [отдельной оси BOM в IR нет](variant.md) |
| **`on_board=no`** | отбрасывается |
| **Keepout-области** (rule areas) | пока не переносятся |
| **Дорожки, переходы и зоны без цепи** | отбрасываются: [медь принадлежит сигналу](signal.md) |
| **Вырожденные дуги** | отбрасываются |
| **Слои вне таблицы** `kicad_layers.tsv` | объект отбрасывается с указанием имени слоя |
| **Стек платы** при отсутствии или порче `stackup` | синтезируется из числа медных слоёв и общей толщины |
| **Начало координат** при отсутствии вспомогательной оси | берётся левый верхний угол страницы |

**`PWR_FLAG` и подобные ERC-директивы** переносятся как обычный символ: его
вывод цепь **не именует**. В IR имя цепи задаёт [символ питания с выводом
`sup`](power-symbol.md), а `PWR_FLAG` — не он.

**Зона, контур которой не эквидистантен**, восстанавливается по осевой; медью
считается фактическая заливка KiCad с пером `min_thickness`. Это аппроксимация
[модели пера](polygon.md), и она записывается в лог.

**Имена цепей приводятся к схемным.** Плата, разошедшаяся со схемой сильнее, чем
переименование, отвергается — см. ниже.

### При экспорте

| Что | Чем становится |
|---|---|
| [Стиль метки](label.md) `crummy` | `global_label` формы `passive`: простой текст у KiCad бывает только у локальных меток |
| Направление вывода модуля `pwr` | формой `passive`: формы «питание» у KiCad нет |
| Устройство, не записанное на экземпляре | поле `Footprint` остаётся пустым |
| Сдвиги плейсхолдеров на элементе платы | пока не переносятся |
| Геометрия на слое без проекции в KiCad | отбрасывается с указанием слоя |
| [Анти-объекты](layer-model.md) вне меди | отбрасываются: keepout из штриха KiCad не выражает |

**Цепь без провода теряет имя.** KiCad вешает имя цепи на метку, а метка обязана
сидеть на проводе. Островок цепи, к которому нечего прицепить, уезжает
безымянным; каждый такой случай попадает в лог.

**Метка, способная слить цепи, помечается отдельно.** Если всякая точка цепи
касается чужого провода, поставленная метка может соединить их — конвертер
выводит предупреждение с требованием проверить результат в KiCad.

## Что отвергается

Список длиннее, чем у [Eagle](conversion-eagle.md), по той же причине, по
которой длиннее вся страница: KiCad допускает состояния, у которых нет
единственного прочтения.

### Схема

| Отказ | Основание |
|---|---|
| **Вложенные листы** глубже одного уровня | [глубина ровно 1](module.md); расплющивание не выполняется никогда |
| **Безпиновый лист, использованный дважды** | без интерфейса выводов он импортируется как самостоятельная страница, и два размещения одного файла прочитать однозначно нельзя |
| **Разная раскладка выводов** у экземпляров одного листа | KiCad разрешает править выводы у одного размещения; [модуль обязан выглядеть одинаково везде](module.md) |
| **Переименование питания на экземпляре** | `Value` символа питания разошёлся с именем цепи в библиотеке; завести отдельный символ питания для этой цепи |
| **Локальное питание на верхнем уровне** | страничная область видимости не представима на едином холсте; сделать глобальным либо перенести схему внутрь листа |
| **Цепь, попадающая более чем в один класс** | [у цепи ровно один класс](class.md); приоритетной агрегации в IR нет |
| **Объект, вылезающий за рамку страницы** | [рамка задаёт печатную страницу](frame.md) |
| **Шинные врезки** | не поддерживаются |

### Плата

| Отказ | Основание |
|---|---|
| **Глухие и погребённые переходы** | [IR выражает только сквозные](via.md) |
| **Зона с `min_thickness=0`** | ширина пера невосстановима; задать её в KiCad и пересохранить |
| **Деталь на плате без схемного экземпляра** | [связность задаёт только схема](layout.md) |
| **Плата, разошедшаяся со схемой по цепям** | признак устаревшей платы: выполнить «Update PCB from Schematic» |

### Отдельный случай: синтезированные выводы модуля

Символы питания и глобальные метки в KiCad **пересекают границу листа молча**.
Чтобы [модуль](module.md) получил честный интерфейс, конвертер достраивает для
них выводы и подводит к ним короткие отрезки на родительском холсте.

Если такой отрезок упирается в чужой вывод или провод, он **слил бы цепи
незаметно**. Это отвергается с указанием, какие именно экземпляры раздвинуть.

## На что обратить внимание после конвертации

По убыванию цены ошибки:

1. **Предупреждения о метках.** Метка, поставленная там, где цепь касается
   чужого провода, способна соединить их. Это единственное место, где перенос
   может изменить **связность**.
2. **Безымянные цепи.** Островок без провода уехал без имени; если имя было
   значимым, его придётся вернуть руками.
3. **Зоны.** Контур восстановлен по осевой, медь соответствует фактической
   заливке KiCad. Проверить зазоры и покрытие.
4. **Формы падов.** Приведённые к прямоугольнику пады перечислены в логе
   поимённо.
5. **Стек платы.** Если `stackup` в источнике отсутствовал, формула синтезирована
   из числа слоёв и общей толщины — реальные толщины подставить самому.
6. **Состав семейств.** Компонент мог собраться из нескольких корпусов сразу.
   Проверить, что разбиение соответствует замыслу, а не случайному разнобою
   свойств `Footprint` в исходной схеме.
