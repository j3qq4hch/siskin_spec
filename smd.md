# `<smd>`

*SMD-пад — площадка на одном медном слое*

> монтажа» — неявное умолчание. См. [reasoning.md](reasoning.md).

## Атрибуты

| Атрибут | Тип / единицы | Смысл |
|---|---|---|
| `name` | Строка **без пробелов** | Имя пада — то, с чем его связывает [`<map>`](map.md) |
| `x` `y` | Целое, [µm](units.md) | Центр |
| `width` `height` | Целое, [µm](units.md) | Размеры до поворота |
| `rot` | Целое, [мград](units.md) | Поворот вокруг центра |
| `layer` | Целое, [номер слоя](layer-model.md) | **Обязателен.** Медный слой: `1` — верх, `−1` — низ |
| `roundness` | Целое, `0`–`100` | Скругление углов. `0` — прямоугольник, `100` — круг |
| `thermals` | Целое, `0`–`100`, умолчание `100` | Тепловой барьер при соединении с [полигоном](polygon.md) |
| `stopmask` | `0` / `1`, умолчание `1` | Автоматическое вскрытие паяльной маски |
| `paste` | `0` / `1`, умолчание `1` | Автоматическая апертура паяльной пасты |

## Пад — точка коммутации

**Через пады и только через них электрический сигнал входит в деталь и выходит из
неё.** Дорожки, полигоны и переходные отверстия — транзит между падами; сама цепь
начинается и кончается здесь.

Со схемной стороны той же точкой служит [вывод символа](pin.md), а связывает их
[`<map>`](map.md). Подробнее — [`<signal>`](signal.md).

## Форма — одна, со шкалой скругления

Пад это **прямоугольник со скруглёнными углами**, и всё:

| `roundness` | Что получается |
|---|---|
| `0` | острый прямоугольник |
| `50` | скруглённые углы |
| `100` | овал; при `width == height` — круг |

Отдельных форм-категорий нет по той же причине, что и у [`<shape>`](shape.md):
изменением размера и коэффициента скругления может быть достигнута любая практические необходимая форма.

**Всё остальное сводится к прямоугольнику** `width`×`height` с записью в лог, не
молча: `trapezoid`, `custom`, `chamfered rectangle` и прочее, что KiCad даёт одним
дропдауном. Точный bbox произвольного полигона не восстанавливается — это была бы
догадка.

## Шкала `thermals` — не то, что кажется

Считается **теплоизоляция**, а не проводимость:

| Значение | Соединение с полигоном |
|---|---|
| `0` | сплошное, барьера нет вовсе |
| `100` | самый тонкий барьер — максимальная теплоизоляция |

Хранится **один процент, а не два булевых** «термо-релиф да/нет» плюс «спиц
столько-то». Абсолютная ширина спицы **не хранится** — она производна, пол задаёт
`width` полигона по [модели пера](polygon.md). Конкретную интерполяцию считает
инструмент-приёмник; IR задаёт только шкалу.

## Один слой — в отличие от сквозных

| | Медь | Имя | Слой |
|---|---|---|---|
| `<smd>` | есть | есть | **обязателен** |
| [`<pad>`](pad.md) | есть | есть | нет — сквозной |
| [`<hole>`](hole.md) | нет | нет | нет — сквозное |

Слой обязателен именно потому, что пад живёт ровно на одном медном этаже. У
сквозных он бессмысленен, а не «подразумевается» — см. [модель слоёв](layer-model.md).

## Пад без меди — не `<smd>`

Если у площадки нет меди вовсе, это **не электрический пад**, а чистая
paste/mask-геометрия. Такое приходит [`<shape>`](shape.md)-ами — по одной фигуре
на каждый затребованный технический слой.

Пад без меди и без единого технического слоя рисовать негде: дропается с записью
в лог.

## Правила

- **Имя без пробелов** — пробел разделяет имена там, где пад перечисляется списком.
- `layer` только медный: `1` или `−1`. Внутренних SMD не бывает.
- **`roundness` — доля от максимально возможного скругления.** Предел задаёт
  короткая сторона: при `100` радиус угла равен её половине, и пад становится
  овалом. Поэтому у квадратного пада `100` даёт круг, а у вытянутого — овал с
  полукруглыми торцами.
- Маска и паста **выводятся автоматически** из геометрии пада; флаги лишь
  отключают вывод, своей геометрии не несут.
