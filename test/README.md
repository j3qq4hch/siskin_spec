# Тестовый корпус грамматики

Проверяет [`appendix/siskin-ir.rnc`](../appendix/siskin-ir.rnc) — и делает это
дважды за свою жизнь: сначала как проверку самой схемы, потом как **эталон
поведения для читалки**. Реализация обязана принимать то же, что принимает
`jing`, и отвергать то же, что отвергает он. Разошлись — баг в одном из двух.

```bash
JING=/c/jing-trang/jing-20241231/bin/jing.jar test/run.sh
```

`jing` берётся из релизов [jing-trang](https://github.com/relaxng/jing-trang)
(проверялось на `V20241231`, нужна Java). Путь задаётся переменной `JING` —
её удобно прописать в профиль оболочки раз и навсегда. Если распакованный
архив положить в `tools/` внутри репозитория, скрипт найдёт его сам.

Флаг `-c` скрипт подставляет сам, но при ручном запуске он обязателен: без
него `jing` ждёт XML-запись схемы и падает с `Content is not allowed in
prolog`, что про настоящую причину не говорит ничего.

## Устройство

Каждый файл проверяет **одно** правило и несёт комментарием, какое именно и
откуда оно. Разрастаться корпус должен так же: одно правило — один файл, иначе
падение перестаёт указывать на причину.

| | |
|---|---|
| `valid/` | обязаны пройти |
| `invalid/` | обязаны быть отвергнуты |

Отрицательных проверок больше, и это правильно: схема ценна не тем, что
пропускает хорошее, а тем, что ловит плохое.

## Что покрыто

**Валидные** — минимальный проект, библиотека с устройством и маппингом,
иерархия с каналом, формула стека, [металлизация торца](../plating.md) с полоской
меди, [анти-медь](../layer-model.md) прямым ребёнком платы, пустое `value`,
[пространство в имени атрибута](../attr.md), версия формата у обоих корней.

Отсутствие `version` отдельным файлом не проверяется: его не пишет ни один
другой документ корпуса, и все они проходят. Это ровно то, чего требует
[version.md](../version.md) — грамматика версию не навязывает, потому что
иначе невалидным стал бы весь корпус, созданный до правила.

Последний стоит отдельного слова: `<attr value="">` — это **объявление ключа, а
не отсутствие значения**. Модель, где пустая строка и отсутствие склеены,
потеряет объявленный ключ на первом же сохранении. Проверка стоит здесь именно
затем, чтобы это всплыло рано.

**Невалидные** — по одному на правило:

| Файл | Правило |
|---|---|
| `rot-45-in-schematic` | в схемном пространстве поворот кратен 90° |
| `fractional-coordinate` | координаты — целые микрометры |
| `layer-number-zero` | `number=0` запрещён: нулю некуда деть знак |
| `bool-as-true` | булево — только `0` и `1` |
| `project-without-schematic` | схема обязательна |
| `two-schematics` | схема ровно одна |
| `modinst-inside-module` | иерархия ровно один уровень |
| `signal-on-silk-layer` | медь цепи лежит только на медных слоях |
| `copper-track-zero-width` | у дорожки на меди толщина ненулевая |
| `copper-line-outside-signal` | медь платы лежит только внутри `<signal>` |
| `copper-polygon-outside-signal` | то же для полигона; анти-медь там законна |
| `via-with-layer` | переход сквозной по построению |
| `pad-name-with-space` | пробел разделяет имена в `<map pad="12 EP">` |
| `stack-starts-with-dielectric` | формула начинается и кончается медью |
| `attr-with-type` | поля `type` у атрибута нет — предназначение выражает префикс имени |
| `wire-with-layer` | у провода схемы `layer` не пишется |
| `version-three-numbers` | версия — два числа, третьего нет |
| `version-leading-zero` | ведущий ноль — не запись числа |

## Границы

Корпус проверяет **только то, что выражает грамматика**. Уникальность имён,
существование ссылок, арифметику вроде `drill < min(width,height)` и согласие
`<contactref>` с `<pinref>` RELAX NG не выражает — это работа валидатора, и её
дом — [ERC](../appendix/erc.md) и [DRC](../appendix/drc.md). Прошёл `run.sh` — значит мусор отсеян, но
документ ещё не корректен.

## Перекрёстная проверка

Схема не должна зависеть от особенностей одного парсера. Второй движок
подключается конвертацией в XML-запись:

```bash
java -jar trang.jar appendix/siskin-ir.rnc appendix/siskin-ir.rng
xmllint --noout --relaxng appendix/siskin-ir.rng test/valid/hello.siprj
```

`jing` и `libxml2` на этом корпусе выносят одинаковые вердикты.
